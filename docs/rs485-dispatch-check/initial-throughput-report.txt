Limits
This establishes observed steady-state throughput and reported error behavior
for one master plus one slave. It does not measure CPU cycles spent inside
communication_dispatch, interrupt jitter, or end-to-end command latency. Exact
CPU timing would require a compatible instrumented build or hardware trace.
No CRC or frame sequence number is present, so these counters cannot establish
bit-perfect delivery or identify balanced loss/duplication. The result does not
validate a six-board load or maximum achievable RS485 throughput.
